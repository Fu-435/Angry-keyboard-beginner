# 雨夜山庄 · 恐怖剧本杀网页游戏

一款可分享、可联机的恐怖题材剧本杀。内置原创剧本《雨夜山庄》，支持 **4 人局** 和 **6 人局**。

## 怎么启动游戏

1. 确保电脑装了 [Node.js](https://nodejs.org)（已装可跳过）。
2. 第一次使用，先安装依赖（只需一次）：
   ```
   npm install
   ```
3. 启动游戏服务器：
   ```
   npm start
   ```
4. 看到提示 `《雨夜山庄》剧本杀已启动：http://localhost:3000` 后，打开浏览器访问 **http://localhost:3000**。

## 怎么玩

- 进入后点击屏幕，选「四人局」或「六人局」，输入昵称，点「开一局」创建房间。
- 房主把 **房间号** 或点「复制邀请链接」发给朋友，朋友打开链接、输入昵称即可加入。
- 人齐后房主点「开始游戏」，随后按右上角按钮逐步推进环节：
  角色分配 → 阅读剧本 → 自我介绍 → 搜证 → 自由讨论 → 投票指认 → 揭晓真相。
- 主持人（旁白）会以漂浮文字形式自动出现，点击屏幕继续。

## 怎么让外地的朋友一起玩（分享联机）

目前游戏在你自己的电脑上运行，只能同一 WiFi 下的设备访问。
要**异地分享**，需要一个公网隧道（推荐 Cloudflare 免费隧道 cloudflared），具体步骤开发阶段会再帮你配置。
